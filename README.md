# SpendWise Dashboard Shell

## Project Description

SpendWise is a personal budgeting and expense tracking dashboard designed to provide users with a simple visual overview of their finances.

This week's project focuses on building the dashboard shell using modern CSS layout techniques.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Dashboard header
- Financial summary cards
- Six spending category cards
- CSS Grid layout
- Flexbox layout
- CSS custom properties
- Responsive design
- Card hover interactions
- Keyboard focus interactions
- Dark theme using prefers-color-scheme

## Spending Categories

The dashboard includes:

1. Food
2. Transport
3. Rent
4. Entertainment
5. Savings
6. Utilities

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Custom Properties
- Media Queries

## CSS Concepts Practiced

### CSS Grid

CSS Grid is used for:

- Overall dashboard layout
- Summary boxes
- Category cards

### Flexbox

Flexbox is used for:

- Sidebar navigation
- Header layout
- User profile
- Dashboard cards
- Card content

### CSS Variables

The project uses CSS custom properties to maintain a consistent theme and make it easier to change colors.

### Responsive Design

The dashboard changes to a single-column layout on screens smaller than 768px.

### Micro-interactions

Dashboard cards use subtle hover and keyboard focus effects with transitions lasting 250ms or less.

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Resize the browser window to test responsiveness.
